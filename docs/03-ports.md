# 3. 端口规划

| 端口 | 用途 | 环境 | 说明 |
|------|------|------|------|
| **4800** | Fastify 统一入口（Web + API） | 生产/开发 | 单进程一体化，唯一对外端口 |
| **4810** | Next.js + http-proxy 开发服务器 | 开发 | 自定义 dev-server 代理 API 到 4800 |
| **4820** | Fastify 开发服务器（API 重载） | 开发 | `fastify-cli` API 热重载（备用） |
| **4830** | Storybook / 组件预览 | 开发 | 可选，UI 组件开发 |

生产环境只需开放 4800 一个端口，4800-4830 按 10 递增。

**开发 vs 生产模式：**

```
开发模式（两个进程，http-proxy 代理）：
  ┌─────────────────────────────────────────────────────┐
  │ Custom Dev Server (:4810)                           │
  │  ┌───────────┐    ┌────────────────┐               │
  │  │ Next.js   │    │ http-proxy     │               │
  │  │ Handler   │    │ /api/* → 4800 │               │
  │  └───────────┘    └────────────────┘               │
  └─────────────────────────────────────────────────────┘
                           │
                           ▼
  ┌─────────────────┐
  │ Fastify Dev     │
  │ :4800           │
  │ (热重载 API)     │
  └─────────────────┘

生产模式（单进程，PM2 守护）：
  ┌────────────────────────────────────────┐
  │ Fastify + @fastify/static             │
  │ :4800                                  │
  │ (Web UI + API + 后台任务)               │
  └────────────────────────────────────────┘
```

**开发服务器代理机制：**

`packages/frontend/dev-server.js` 使用 `http-proxy` 将 `/api/*` 请求转发到后端，避免 CORS 问题，前端 `API_BASE = ''` 无需感知后端端口。

```bash
# 启动开发环境
cd packages/frontend && npm run dev  # 端口 4810
cd packages/backend && npm run dev     # 端口 4800
```
