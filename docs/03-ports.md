# 3. 端口规划

| 端口 | 用途 | 环境 | 说明 |
|------|------|------|------|
| **4800** | Fastify 统一入口（Web + API） | 生产 | 单进程一体化，唯一对外端口 |
| **4810** | Next.js 开发服务器 | 开发 | `next dev` 热重载前端 |
| **4820** | Fastify 开发服务器 | 开发 | `fastify-cli` API 热重载 |
| **4830** | Storybook / 组件预览 | 开发 | 可选，UI 组件开发 |

生产环境只需开放 4800 一个端口，4800-4830 按 10 递增。

**开发 vs 生产模式：**

```
开发模式（两个进程，支持热重载）：
  ┌─────────────────┐     ┌─────────────────┐
  │ Next.js Dev     │     │ Fastify Dev     │
  │ :4810           │────▶│ :4820           │
  │ (热重载 UI)      │     │ (热重载 API)     │
  └─────────────────┘     └─────────────────┘

生产模式（单进程，PM2 守护）：
  ┌────────────────────────────────────────┐
  │ Fastify + @fastify/static             │
  │ :4800                                  │
  │ (Web UI + API + 后台任务)               │
  └────────────────────────────────────────┘
```
